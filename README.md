# uzma-portfolio

Personal site of Uzma Hamid: a horizontal-scroll "field guide" (collector, story, timeline),
a vertical work index with a page per project, and a few small experiments.

Built with React + Vite. Design inspired by [Nidhi Prajapati](https://www.somehowliving.tech/).

```bash
npm install
npm run dev     # http://localhost:3001
npm run build   # production build in dist/
```

- `src/data.js`: all copy (objects, story, timeline, projects, playlists, past versions)
- `src/cases.json`: long-form project write-ups
- `src/App.jsx`: home page; `src/ProjectPage.jsx`: `/projects/<slug>`
- `public/media/`: images, videos and the custom cursor

Earlier versions of the site live in [uzma_pw](https://github.com/uzmahamid01/uzma_pw).
